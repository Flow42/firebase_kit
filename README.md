# firebase_kit

Reusable, **state-management-agnostic** Firebase building blocks shared across
Flutter apps. Extracted from `skilltree_app`; intended to be consumed by any app
that talks to Firebase Auth + Firestore.

## What's in it

| Area | API | Notes |
|------|-----|-------|
| Auth abstraction | `AuthService`, `AuthUser`, `AuthException` | No Firebase types leak to callers; no Riverpod/Bloc dependency. |
| Auth implementation | `FirebaseAuthService` | Backed by `firebase_auth`; injects `FirebaseAuth` for testability. Supports anonymous, email/password, Google, and anonymous→email linking. |
| Emulator wiring | `connectToFirebaseEmulators`, `FirebaseEmulatorConfig` | Points the default Auth/Firestore instances at the Local Emulator Suite. |

`firebase_options.dart` (generated by `flutterfire configure`), Firestore
security rules, indexes, and concrete Firestore repositories stay **per-app** —
only the app-agnostic pieces live here.

## Usage

```yaml
# consuming app's pubspec.yaml
dependencies:
  firebase_kit:
    path: ../firebase_kit          # or a git dependency once published
```

```dart
import 'package:firebase_core/firebase_core.dart';
import 'package:firebase_kit/firebase_kit.dart';

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);

  const useEmulator = bool.fromEnvironment('USE_FIREBASE_EMULATOR', defaultValue: true);
  if (useEmulator) {
    await connectToFirebaseEmulators(config: FirebaseEmulatorConfig.fromEnvironment());
  }

  runApp(MyApp(authService: FirebaseAuthService()));
}
```

Wrap `AuthService` in whatever state layer the app uses (Riverpod provider,
`ChangeNotifier`, Bloc, …) — the package intentionally takes no position on that.

## Emulator test scaffolding

`scaffold/` holds copy-in templates (not shipped as Dart library code):

- `test_emulator.sh` — wraps `firebase emulators:exec` around a headless-Chrome
  `flutter drive`. Copy into `scripts/` and set `FIREBASE_PROJECT_ID` /
  `TEST_TARGET` (or edit the defaults).
- `integration_test.dart` — the 3-line `flutter drive` driver; copy into the
  app's `test_driver/` (it must live in the consuming app).

Your integration test connects to the emulators with the same helper:

```dart
setUpAll(() async {
  await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);
  await connectToFirebaseEmulators(config: FirebaseEmulatorConfig.fromEnvironment());
});
```

## Version note

Pinned to `firebase_core ^4 / firebase_auth ^6 / cloud_firestore ^6`. Apps on
older Firebase majors must upgrade before consuming this package.
